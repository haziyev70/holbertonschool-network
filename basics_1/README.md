# Holberton School - Networking (basics_1)

This directory contains Bash scripts and network configurations for the Holberton School Networking curriculum, focusing on hostname resolution, `/etc/hosts` file modifications, and network interface analysis.

## Tasks
* **0-change_your_home_IP**: A Bash script that modifies `/etc/hosts` to point `localhost` to `127.0.0.2` and `facebook.com` to `8.8.8.8`.
